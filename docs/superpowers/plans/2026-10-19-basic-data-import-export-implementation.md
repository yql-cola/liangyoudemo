# 基础资料导入与导出实施计划

> 本计划在当前工作区逐项执行；保留既有未提交改动。

**目标：** 七类基础资料支持 XLSX 模板与整批导入、跨页勾选导出；现有 Excel 表头和库存流水类型显示中文。

**架构：** 使用独立批量接口和服务复用基础资料创建校验；现有 GET 导出保持兼容，新增 POST 按 ID 导出。前端七页继续复用 `BasicDataPage`。

**技术栈：** Spring Boot 3、Apache POI、MyBatis-Plus、Vue 2、Element UI、JUnit 5、Jest。
