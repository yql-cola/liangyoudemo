# 基础资料批量导入、勾选导出与中文显示需求设计

日期：2026-10-19  
状态：已确认需求设计，尚未实施

## 1. 目标与范围

为七类基础资料增加 XLSX 批量导入和列表勾选导出：商品、商品分类、单位、商品单位换算、仓库、供应商、客户。系统所有**已有 Excel 导出**（基础资料、库存、统计）的字段表头统一使用中文。库存流水的流水类型、业务类型等固定类型值采用集中枚举，接口保留稳定代码，前端和 Excel 显示中文。

本次勾选导出仅覆盖七个基础资料菜单；库存和统计现有导出只调整中文表头及相关类型值显示，不增加复选框。采购单、销售单、库存台账等业务数据不纳入批量导入。

## 2. 现状与改造位置

- 七个基础资料页面共用 `frontend/src/views/basic/BasicDataPage.vue` 和 `frontend/src/api/basic/index.js`；后端分别由七个基础资料 Controller 提供接口。
- 现有基础资料导出按查询条件取全部匹配记录，忽略分页参数；`BasicDataService.exportRows` 已为这些导出使用中文表头。
- 库存汇总、批次、流水和统计页面有独立 Excel 导出。通用 `ExcelExportService.export` 会把数据 Map 的键写成表头，因此应检查每个导出调用方，避免英文属性名成为 Excel 表头。统计场景导出目前已经显式使用中文键，仍须回归验证。
- 库存流水的 `flowType`、`bizType` 当前是字符串，前端列表直接展示原值。现有写入链路包含入库、出库、撤销和库存调整类型。

## 3. 批量导入

### 3.1 页面流程

七个基础资料页面增加“下载导入模板”和“批量导入”入口，统一放在列表工具栏，并与新增、导出、刷新保持一致的按钮样式。每类资料使用独立的中文列名 XLSX 模板，弹窗显示所选文件、上传状态和导入结果。上传期间阻止重复提交。成功后刷新当前列表；失败时展示总行数及每条错误对应的 Excel 行号、列名和原因，便于用户修正后重传。

导入采用**整批校验、整批写入**：有任一数据行不合法，整批不写入；全部通过后在一个事务内提交。上传文件遇到已有编码或已有单位换算关系时报错，不更新、不覆盖原资料。同一个文件内的重复记录也视为错误。空行不计入数据行数。

### 3.2 模板与关联字段

| 资料 | 模板业务列 | 关联规则 |
| --- | --- | --- |
| 商品分类 | 分类名称、父分类、排序、状态、备注 | 根分类父分类留空；非根分类填可唯一识别的父分类路径 |
| 单位 | 单位编码、单位名称、状态、备注 | 单位编码唯一 |
| 仓库 | 仓库编码、仓库名称、联系人、联系电话、地址、状态、备注 | 仓库编码唯一 |
| 供应商 | 供应商编码、供应商名称、联系人、联系电话、地址、税号、开户行、银行账号、状态、备注 | 供应商编码唯一 |
| 客户 | 客户编码、客户名称、联系人、联系电话、地址、税号、开户行、银行账号、状态、备注 | 客户编码唯一 |
| 商品 | 商品编码、商品名称、分类、品牌、规格、条码、图片地址、基础单位、保质期天数、状态、备注 | 分类用完整路径定位；基础单位用单位编码定位 |
| 单位换算 | 商品编码、源单位编码、目标单位编码、换算比率、状态、备注 | 用编码定位关联资料；同一商品的源单位和目标单位组合唯一 |

模板的状态列使用“启用”“停用”；服务器转换成现有状态值。商品编码、条码、银行账号等按文本读取，保留前导零；换算比率和保质期天数按严格数值规则解析。服务端校验文件确为 `.xlsx`，检查表头、必填项、字段长度、唯一性、关联资料存在且可用，以及现有新增接口的业务约束。重复或缺失表头、非法数值、歧义关联和超出上传限制均返回明确错误。公式不执行。单文件限制为 5 MB、2000 条数据行；前端显示同一限制。

为降低关联歧义，建议按“分类、单位、仓库、供应商、客户 → 商品 → 单位换算”的顺序导入。分类模板允许引用已经存在的父分类；同文件中的父子分类按层级解析，无法唯一定位或存在循环时整批失败。

### 3.3 接口与权限

沿用现有 `/api/v1/basic` 路径、`ApiResponse` 响应包装及资源权限风格：

| 接口 | 用途 | 权限 |
| --- | --- | --- |
| `GET /api/v1/basic/{resource}/import/template` | 下载对应资源的中文 XLSX 模板 | `basic:{key}:import` 或 `basic:{key}:create` |
| `POST /api/v1/basic/{resource}/import` | `multipart/form-data` 上传字段 `file` | `basic:{key}:import` 或 `basic:{key}:create` |

`resource` 与现有七个资源路径一致（例如 `products`）；`key` 沿用现有权限名中的单数键（例如 `product`，单位换算为 `unit-convert`）。导入结果包含 `totalRows`、`successRows`、`failedRows`、`errors`，其中错误项为 `{rowNumber, columnName, message}`；`rowNumber` 对应 Excel 可见行号，第一行为表头。校验失败时 `successRows=0`，且数据库无本批新增记录。权限需要同时进入权限种子、后端授权与前端按钮控制。

## 4. 勾选导出

七个基础资料列表首列增加复选框，显示已选数量并可清空。选择以记录 ID 去重、跨分页保留；切换资料菜单或离开页面清空。分类树中的父分类和子分类独立勾选，勾选父节点不会自动勾选子节点。

- **有勾选**：仅导出提交的记录 ID，不受当前页限制。若任一 ID 已删除、无权访问或不属于该资源，整次导出返回明确错误，避免用户误以为文件完整。
- **无勾选**：按当前查询条件导出全部匹配记录，忽略 `pageNum/pageSize`；这沿用现有导出语义。筛选条件为空时即导出该资源全部可见记录。
- 导出文件使用固定列顺序和中文表头；状态及类型值在 Excel 中使用中文。查询结果为空时仍生成带中文表头的 XLSX。

保留现有 `GET /api/v1/basic/{resource}/export` 供无勾选导出使用，并增加 `POST /api/v1/basic/{resource}/export` 接收 `{ids: [...]}` 下载勾选记录。使用 POST 避免大量 ID 超出 URL 长度。两者都校验现有 `basic:{key}:export` 权限。前端通用基础资料 API 根据选择状态调用对应接口。

## 5. 已有导出的中文表头

审查所有已有 Excel 导出的表头映射，范围包含七类基础资料、库存汇总、批次库存、库存流水及统计场景。各导出采用显式“字段键 → 中文列名”配置，并固定列顺序；不能把 Java 属性名或查询结果键直接作为最终表头。中文名称与页面用语保持一致。无数据时仍输出对应表头；编码、条码、单号、银行账号等按文本写入，避免 Excel 改写前导零或长编号。

此次只统一既有导出的字段名称和类型值呈现，不改变库存、统计导出的筛选及数据范围。基础资料现有中文列名也纳入回归检查，确保新增的勾选导出保持一致。

## 6. 类型枚举与中文显示

后端为固定类型建立集中枚举，约束新写入的代码；前端集中维护代码到中文的映射，用于列表、详情和筛选展示。接口继续返回稳定代码，避免破坏现有 API；Excel 导出时按同一语义转中文。历史未知代码显示原值，避免空白；发现未知代码时补充映射或修正数据来源，不静默改写历史记录。

库存流水当前代码与中文名称：

| 字段 | 代码 | 显示名称 |
| --- | --- | --- |
| `flowType` | `purchase_in` | 采购入库 |
| `flowType` | `purchase_in_reverse` | 采购入库撤销 |
| `flowType` | `sale_out` | 销售出库 |
| `flowType` | `sale_out_reverse` | 销售出库撤销 |
| `flowType` | `adjust` | 库存调整 |
| `bizType` | `purchase_in` | 采购入库 |
| `bizType` | `purchase_in_reverse` | 采购入库撤销 |
| `bizType` | `sale_out` | 销售出库 |
| `bizType` | `sale_out_reverse` | 销售出库撤销 |
| `bizType` | `inventory_adjust` | 库存调整 |

实施时审计其余确实具有固定取值的类型字段，再复用这一模式；普通自由文本字段不改成枚举。

## 7. 前后端协作与验收

前后端先约定七份模板的列名、关联定位方式、导入错误结构和导出请求结构。后端实现模板生成、解析校验、事务写入、权限及中文导出；前端实现通用导入交互、错误展示、跨页选择和类型中文显示。最后按七类真实模板联调。

验收标准：

1. 七类模板可下载；合法文件导入成功；重复编码、非法数值、缺列、无效关联及文件内重复能定位 Excel 行列，错误批次没有部分写入。
2. 没有导入和新增权限时导入接口拒绝访问，页面隐藏导入入口；没有导出权限时导出接口拒绝访问，页面隐藏导出入口。服务端独立校验上传大小、行数和文件内容。
3. 基础资料跨页勾选后只导出所选；清空选择后导出当前筛选条件下全部匹配记录，且不受分页限制。
4. 所有已有 Excel 导出的表头为中文；空结果也有中文表头；类型值在页面和 Excel 为中文，接口代码保持稳定。
5. 分类父子关系、已停用资料、已删除选择项、重复上传同一文件以及撤销流水类型均有对应边界验证。
